## 1. نظرة عامة على المشروع والهوية الأصلية (Project Overview & Identity)
**Cue Masters: Local Pool** هي لعبة بلياردو أصيلة عالية الدقة، صُممت انطلاقاً من المرجع البصري للعبة البلياردو والركائز الأساسية المحددة:
- **فيزياء حقيقية مستمرة**: حساب التصادمات عبر 8 خطوات فرعية للإطار (Sub-stepping) لمنع الاختراق أو اهتزاز الكرات عند السكون، مع ارتداد مرن، وتأثيرات الدوران (English / Spin)، واحتكاك دحرجة واقعي.
- **استقلالية تامة دون إنترنت (100% Offline-First)**: جميع أوضاع اللعب الفردي، والتدريب الحر، وتحديات المهارة، والبطولات المحلية الإقصائية (8 لاعبين)، والمتجر وتسمية العصا (`NAME THIS CUE!`) تعمل كلياً على الجهاز دون أي اتصال خارجي.
- **لعب جماعي محلي متعدد**:
  1. **اللعب على شاشة واحدة (Pass & Play / Hot-Seat)**.
  2. **غرف الشبكة المحلية (Wi-Fi / LAN)** عبر بث واكتشاف محلي برمز غرفة سريع دون إنترنت، مع نموذج تحكيم مرجعي للمضيف (Host-Authoritative).
- **إمكانية الوصول الشاملة (Full Accessibility)**:
  - دعم كامل للغة العربية (RTL أصيل) والإنجليزية.
  - وضع التباين العالي (High Contrast Mode) مع شارات هندسية للكرات السادة (Solids) والمخططة (Stripes) ونقاط أراميث للكرة البيضاء لمنع الاعتماد على اللون وحده لتمييز الكرات.
  - خيار تقليل الحركة (Reduced Motion) لراحة العين.
  - تحكم دقيق بحساسية السحب للتصويب وموضع مقياس القوة (يمين / يسار).
  - فصل كامل لتعطيل الموسيقى الهادئة، والمؤثرات الصوتية، والاهتزاز اللمسي (Haptics) على حدة.

## 3. تعليمات البناء والتشغيل المحلي (Build & Run Instructions)

### المتطلبات الأساسية (Prerequisites)
- **Node.js**: الإصدار 18 فما فوق (أو 20 LTS).
- **مدير الحزم**: `npm` (أو `pnpm` / `yarn`).

### خطوات التشغيل المحلي (Local Development)
```bash
# 1. تثبيت الاعتماديات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. فتح الرابط في المتصفح:
# http://localhost:3000
```

### خطوات بناء حزمة الإنتاج (Production Build)
```bash
# فحص الأنواع واكتمال البناء
npm run build

# معاينة الحزمة المبنية
npm run preview
```

## 4. إعدادات تصدير Android وأذونات الشبكة المحلية (Android Export & Permissions)

عند تغليف التطبيق كـ Android App (عبر Godot 4 أو Capacitor / Trusted Web Activity / WebView Native Shell):

### الأذونات المطلوبة في `AndroidManifest.xml`:
```xml
<!-- أذونات الاتصال بالشبكة المحلية Wi-Fi / LAN دون الحاجة للإنترنت الخارجي -->
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
<uses-permission android:name="android.permission.CHANGE_WIFI_MULTICAST_STATE" />
<uses-permission android:name="android.permission.INTERNET" />

<!-- إذن الاهتزاز للملاحظات اللمسية Haptic Feedback -->
<uses-permission android:name="android.permission.VIBRATE" />
```

### قيود وضوابط البلوتوث (Bluetooth Constraints & Native Bridge):
- **القيود التقنية**: متصفحات الويب تدعم `Web Bluetooth API` كعميل مركزي (Central / Client) فقط، **ولا تسمح** بالبث كخادم طرفي (Peripheral / Advertising) لاستضافة مباريات الند للند (P2P).
- **الحل المعتمد في المشروع**:
  1. جعل **Wi-Fi / LAN المحلي** هو مسار الاتصال الأساسي الأكثر موثوقية واستقراراً دون الحاجة لأي خادم إنترنت.
  2. توثيق واجهة `BluetoothAdapter` وتحديد قيودها بشفافية داخل الواجهة، دون عرض أزرار وهمية أو وعود غير قابلة للتحقق.
  3. عند التصدير لـ Android الأصلي مع إضافة Bluetooth Native Plugin (مثل BLE Peripheral Server)، يتم ربط الحزم بنفس واجهة `INetworkAdapter` الموحدة.

## 5. دليل اللعب الجماعي دون إنترنت (Offline Multiplayer Guide)

### أ. اللعب على نفس الشاشة (Hot-seat / Pass & Play)
- الخيار الأسرع والأنسب لشخصين يستخدمان نفس الهاتف أو الحاسوب اللوحي.
- يتبادل اللاعبان الأدوار تلقائياً على نفس الجهاز، مع ظهور تنبيه بصري وصوتي عند تبديل الدور واسم اللاعب النشط.

### ب. اللعب عبر الشبكة المحلية (Wi-Fi / Local LAN)
1. **المضيف (Host)**:
   - يضغط على "إنشاء غرفة محلية".
   - يحدد الوضع (8-Ball أو 9-Ball) ونظام القواعد وعدد الجولات (Best of 1, 3, 5).
   - يحصل على رمز غرفة قصير من 4 أحرف (مثل `POOL-8821`).
2. **اللاعب المنضم (Client)**:
   - يضغط على "الانضمام لغرفة محلية".
   - يكتشف الغرفة المتاحة على الشبكة بنقرة واحدة، أو يدخل الرمز يدوياً.
3. **نموذج المباراة**:
   - **Host-Authoritative**: المضيف هو المرجع الرسمي لحساب التصادمات والتحكيم ومنع التلاعب.
   - **مهلة انقطاع 30 ثانية**: في حال تحويل التطبيق للخلفية أو انقطاع الاتصال اللحظي، يُمنح اللاعب مهلة 30 ثانية لإعادة الاتصال دون احتساب هزيمة فورية غير عادلة.

## 6. توثيق القواعد، الذكاء الاصطناعي، والحفظ المحلي

### أ. قواعد الكرة الثامنة (8-Ball)
- **WPA Official (الرسمي)**: الطاولة مفتوحة بعد الضربة الافتتاحية حتى إسقاط كرة قانونية. الأخطاء تمنح الخصم "كرة في اليد" في أي مكان على الطاولة. إسقاط الكرة 8 قبل تصفية المجموعة أو مع الكرة البيضاء يعد خسارة فورية. إسقاط الكرة 8 قانونياً بعد تصفية المجموعة يحقق الفوز.
- **House Rules (القواعد المنزلية)**: إسقاط الكرة 8 في الضربة الافتتاحية يمنح الفوز فوراً! الأخطاء تمنح وضع الكرة البيضاء خلف خط الرأس (Kitchen Line).

### ب. قواعد الكرة التاسعة (9-Ball)
- يجب أن تلمس الكرة البيضاء أولاً الكرة ذات الرقم الأصغر الموجودة على الطاولة.
- الفوز يتحقق بإسقاط الكرة رقم 9 في أي ضربة قانونية (سواء مباشرة أو بضربة مركبة Combination Shot).

### ج. الذكاء الاصطناعي (AI Difficulty Tiers)
- **مبتدئ (Easy)**: تصويب مباشر، هامش خطأ في الزاوية $\pm 7^\circ$ وخطأ قوة $\pm 20\%$.
- **متوسط (Medium)**: تخطيط أساسي، هامش خطأ $\pm 3.5^\circ$ وخطأ قوة $\pm 10\%$.
- **محترف (Hard)**: تصويب دقيق مع مراعاة الحواجز والارتداد، هامش خطأ $\pm 1.2^\circ$.
- **أستاذ (Master)**: تصويب جراحي مع اختيار زاوية التموضع للضربة التالية.

### د. الحفظ المحلي والتعافي التلقائي (Storage & Auto-Recovery)
- حفظ محلي في `localStorage` بصيغة مهيكلة (v2).
- **آلية التعافي من التلف (Anti-Corruption)**: في حال تعطل ملف الحفظ أو عدم اكتماله، يقوم النظام باستعادة القيم السليمة تلقائياً وتدوين الحادث في سجل التشخيص دون مسح بيانات المستخدم بصمت.
- دعم تصدير واستيراد بيانات الحفظ يدوياً بصيغة JSON كنسخة احتياطية.
